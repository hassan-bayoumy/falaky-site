# falaky-site

Public static pages for [Falaky](https://falaky.app): the privacy policy (EN + AR) and a placeholder landing page, served by GitHub Pages at https://falaky.app (custom domain; the `CNAME` file binds it — keep it).

The policy's source of truth is `public/privacy_policy.html` in the (private) app repository — copy it here when it changes. The app itself is not in this repository.
